# Интерактивная политическая карта Беларуси (Пилотный слой: г. Гродно)

[![Deploy to GitHub Pages](https://github.com/RDincorp/PolitInfoRoB_Demo_Grodno_City/actions/workflows/deploy.yml/badge.svg)](https://github.com/RDincorp/PolitInfoRoB_Demo_Grodno_City/actions/workflows/deploy.yml)

Масштабируемая информационно-справочная веб-платформа, агрегирующая структурированные официальные данные об органах власти, депутатском корпусе, избирательных округах, компетенциях и контактной информации Республики Беларусь и города Гродно.

---

## 🏛 Основные разделы и возможности

1. **Главная страница (`/`)**
   - **Универсальный поиск**: быстрый сквозной поиск по людям, органам власти, избирательным округам, вопросам/ЖКХ и территориям с мгновенной фильтрацией.
   - **Интерактивная карта**: векторный просмотр границ Беларуси и города Гродно с привязкой избирательных округов и учреждений.
   - **Схема государственного устройства**: наглядная конституционная структура ветвей власти Республики Беларусь.

2. **Паспорт территории города Гродно (`/territories/grodno`)**
   - Представительная власть (Гродненский городской Совет депутатов 29-го созыва).
   - Исполнительная власть (Гродненский горисполком, администрации Ленинского и Октябрьского районов).
   - Судебная власть (Суды Ленинского и Октябрьского районов г. Гродно).
   - Избирательные округа и прикрепленные официальные источники.

3. **Реестр депутатов и должностных лиц (`/people` и `/people/[slug]`)**
   - Персональные карточки депутатов Горсовета 29-го созыва и руководителей органов.
   - Подтвержденные графики личного приёма граждан, адреса приёмных, телефоны для записи.
   - Закрепленные избирательные округа и знаки подтвержденного происхождения данных (`ProvenanceBadge`).

4. **Органы власти и управления (`/institutions` и `/institutions/[slug]`)**
   - Структура горисполкома, районных администраций, отделов и управлений (ЖКХ, архитектура, образование, загс).
   - Руководство с графиками приёма и компетенции.

5. **Избирательные округа (`/districts` и `/districts/[slug]`)**
   - Границы избирательных округов № 1–30 по г. Гродно с перечнями улиц и домов.
   - Избранный депутат округа с прямым переходом в его приёмный график.

6. **Куда обращаться / Компетенции (`/competences` и `/competences/[slug]`)**
   - Навигатор решения вопросов граждан (ЖКХ, перепланировка и строительство, детские сады/школы, загс) с контактами и ссылками на НПА.

7. **Реестр источников и цифровых слепков (`/sources` и `/sources/[id]`)**
   - Прозрачный публичный реестр официальных государственных источников (`grodno.gov.by`, `pravo.by`, `president.gov.by`).
   - История снапшотов с SHA-256 хешами контента.

8. **Административная панель верификации (`/admin`)**
   - Панель мониторинга (`/admin/dashboard`).
   - Очередь двухколоночного сравнения изменений (`/admin/review-queue`) перед публикацией в базу данных.
   - Управление источниками и запуск парсера (`/admin/sources`).

---

## 🛡 Принципы данных и архитектуры

- **Data Provenance**: Каждый факт в системе привязан к конкретному источнику (`Source`) и неизменяемому слепку (`SourceSnapshot`).
- **Строгость и достоверность**: В базу попадают только подтвержденные официальные данные. При отсутствии информации поле помечается как `null` / "Не указан в официальных источниках", без домысливания.
- **SSRF Guard**: Модуль безопасности парсинга блокирует обращения к приватным IP-адресам (RFC 1918) и разрешает запросы только к белому списку государственных доменов.
- **Масштабируемость**: Единая архитектура сущностей (`Territory`, `Person`, `Institution`, `ElectoralDistrict`, `Competence`) позволяет бесшовно подключать Минск, Брест, Витебск, Гомель, Могилёв и все районы Беларуси.

## 🚀 Установка и локальный запуск

```bash
# Клонирование репозитория
git clone https://github.com/RDincorp/PolitInfoRoB_Demo_Grodno_City.git
cd PolitInfoRoB_Demo_Grodno_City

# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev
```

Откройте в браузере: [http://localhost:3000](http://localhost:3000)

## 🧪 Запуск тестов и сборка

# Запуск модульных тестов (Vitest)

npm run build

## 🌐 Публикация на GitHub Pages

Проект настроен для автоматической сборки и публикации через **GitHub Actions**:
1. Workflow настроен в файле `.github/workflows/deploy.yml`.
2. При каждом `git push` в ветку `main` запускаются автоматические тесты, генерируется статический экспорт Next.js (`output: 'export'`) и результат развертывается на GitHub Pages.
3. В настройках вашего GitHub репозитория:
   - Перейдите в **Settings** $\rightarrow$ **Pages**.
   - В секции **Build and deployment** выберите **Source: GitHub Actions**.
